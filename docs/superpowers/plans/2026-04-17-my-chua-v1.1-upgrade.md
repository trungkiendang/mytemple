### Task 1: New Dependencies & Data Models

**Files:**
- Modify: `pubspec.yaml`
- Create: `lib/models/calendar_event.dart`, `lib/services/tts_service.dart`

- [ ] **Step 1: Cấu hình pubspec.yaml**
Add `flutter_tts: ^4.2.2` and `uuid: ^4.4.0`. Run `flutter pub get`.

- [ ] **Step 2: Tạo model CalendarEvent**
```dart
import 'package:hive/hive.dart';
part 'calendar_event.g.dart';

@HiveType(typeId: 1)
class CalendarEvent extends HiveObject {
  @HiveField(0)
  final String id;
  @HiveField(1)
  final String title;
  @HiveField(2)
  final DateTime date;
  @HiveField(3)
  final bool isLunar;
  @HiveField(4)
  final bool reminderEnabled;

  CalendarEvent({
    required this.id,
    required this.title,
    required this.date,
    this.isLunar = false,
    this.reminderEnabled = true,
  });
}
```

- [ ] **Step 3: Chạy build_runner**
Run `flutter pub run build_runner build`.
