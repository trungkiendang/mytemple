# AGENTS.md

## Commands
- `flutter pub get` — install deps
- `dart run build_runner build --delete-conflicting-outputs` — regenerate Hive `.g.dart` adapters (typeId 0=Scripture, 1=CalendarEvent)
- `flutter analyze` — lint/static analysis (uses `flutter_lints`, no custom rules)
- `flutter test` — run tests (single smoke test at `test/widget_test.dart`)
- `flutter run` — run on connected device/emulator
- `flutter run -d chrome` — run on web (Firebase web config is hardcoded in `lib/main.dart:30-38`)
- `cd scripts && npm install && node upload_to_firebase.js` — seed Firestore with scripture data from `docs/firebase_seed.json` (requires `scripts/serviceAccountKey.json`, gitignored)

## Architecture

### Entrypoint
`lib/main.dart` — initializes: `HiveService.init()` → `NotificationService().init()` → `Firebase.initializeApp()` → `FirebaseAuth.instance.signInAnonymously()` → `runApp(MyApp)` with Provider-wrapped MaterialApp.

### Navigation
Five-tab `BottomNavigationBar` with `IndexedStack` — monk_bell, scriptures, incense, calendar, profile. Screens use `AutomaticKeepAliveClientMixin` to survive tab switches.

### State Management
Provider. Five providers registered in `MultiProvider`: `MonkBellProvider`, `IncenseProvider`, `EventProvider`. `TtsService` is also a `ChangeNotifier` provided at root.

### Firebase
- Auth: anonymous sign-in on startup (required for Firestore security rules)
- Firestore collections: `scriptures/`, `stats/global_stats` (global_taps, online_users), `users/{uid}/user_events`
- Some providers (`MonkBellProvider`, `FirebaseService`) gracefully degrade to mock data when Firebase is unavailable (check `Firebase.apps.isNotEmpty`)

### Local Storage
Hive boxes: `scriptures` (typeId 0), `events` (typeId 1), `settings` (untyped). Services layer in `lib/services/hive_service.dart`.

### Services
- `HiveService` — static methods, all-in-one wrapper
- `NotificationService` — singleton mock (only `debugPrint`); not wired to `flutter_local_notifications` yet
- `TtsService` — ChangeNotifier, uses `flutter_tts` with Vietnamese voice (`vi-VN`)
- `FirebaseService` — instance, fetches scriptures with optional `sect` filter

### Assets
- 3D models (generated by `scripts/generate_models.js`): `assets/models/mo.glb`, `assets/models/incense_censer.glb`
- Bundled scriptures (offline fallback): `assets/data/scriptures.json`
- App icon sources: `assets/icon/` (generated by `scripts/generate_app_icon.py`)
- Audio: `assets/audio/bell_sound.wav`

### Scripts Firestore Seeder
Node.js script at `scripts/upload_to_firebase.js`. Uses `firebase-admin`. Data source: `docs/firebase_seed.json`. Collections seeded: `scriptures`, `stats/global_stats`.

## Key Conventions
- All UI strings in Vietnamese
- Theme colors in `lib/core/app_theme.dart` (darkWood, woodBrown, parchment, etc.)
- Feature directories (`lib/features/{monk_bell,incense,scriptures,calendar,profile,community}/`) each contain their own screen + provider
- Models in `lib/models/` use Hive annotations with `@HiveType` and `@HiveField`; generated adapters committed
- Package name for native configs: `com.kun.temple`
- No git hooks, no CI/CD workflows

## Notes (v1.2)
- Mõ screen input is a Flutter overlay (Listener) above the 3D view; on web `#monk-bell { pointer-events: none }` in `web/index.html` lets events through. The 2D mallet is drawn by `_MalletPainter`.
- `o3d` controller calls (`customJsCode`, camera/animation) do NOT work on web (the view's inline script never runs). The incense screen therefore uses a fixed camera and draws sticks, glowing tips, ash, sparks and smoke itself (`lib/features/incense/incense_effects.dart`, `IncenseFx`), projecting 3D points with the same camera constants as the O3D widget (model-viewer renders `field-of-view: 30deg` with an effective vertical angle of ~23.3° — measured with marker spheres at known positions; re-measure if the model's bounding box or camera settings change). Burn progress is wall-clock based (`IncenseProvider.burnProgress`), so the sticks burn down exactly over the chosen time; smoke style depends on the stick count (1 straight column, 3 braided, 5 swirling plume).
- Prayer reading (karaoke/TTS) during incense: `lib/features/incense/prayer_provider.dart` (state + timing), `prayer_widgets.dart` (sheet + reader card), data in `assets/data/prayers.json`; `TtsService.speakAndWait` awaits each line.
- Start-up: `main()` paints `BootstrapApp` (splash, `lib/features/splash/splash_screen.dart`) while `_initialize()` runs; web has an HTML splash in `web/index.html` removed on `flutter-first-frame`; native splash generated by `flutter_native_splash` (config in pubspec).
- Analytics wrapper: `lib/services/analytics_service.dart` (see `docs/ANALYTICS.md`; web needs `--dart-define=GA_MEASUREMENT_ID`).
- Custom nav/feature icons live in `lib/core/app_icons.dart` (`AppIcon.moBell/incense/scripture/lunar/lotus`).
- Firebase findings and required console setup: `docs/FIREBASE.md`; store publishing: `docs/STORE_PUBLISHING.md`.
